## 📖 About

**Nammalvar Eyarkaiyagam** is a home business online shopping platform dedicated to providing 100% organic and natural farm products. We offer a wide range of traditional items including cold-pressed oils, ancient rice varieties, natural spices, pulses, herbal health products, and more — all cultivated following sustainable agroecological principles.

Our mission is to preserve India's rich agricultural heritage while promoting healthy, chemical-free living.

## 🚀 Getting Started

### Prerequisites

- **Node.js** (v18 or higher recommended)
- **npm** or **yarn** package manager

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/sanggitsaaran/Nammalvar_Eyarkaiyagam.git
   cd Nammalvar_Eyarkaiyagam
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start development server**
   ```bash
   npm run dev
   ```

4. **Open in browser**
   ```
   http://localhost:5173
   ```

### Available Scripts

| Command | Description |
|---------|-------------|
| `npm run dev` | Start development server with hot reload |
| `npm run build` | Build production-ready bundle |
| `npm run preview` | Preview production build locally |
| `npm run lint` | Run ESLint for code quality checks |
